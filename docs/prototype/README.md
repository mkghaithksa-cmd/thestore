# منصة غيث لتنقية المياه: النموذج التفاعلي للتصميم

نموذج أولي (Prototype) لتصميم واجهات المنصة الثلاث، يُعرض على الجهة للمراجعة قبل كتابة الكود الفعلي. **ليس نظاماً حقيقياً:** لا قاعدة بيانات ولا دفع ولا واتساب، وكل الأرقام والبيانات أمثلة.

## الملفات
| المسار | الوصف |
|---|---|
| `prototype/customer-site.html` | موقع العميل: الرئيسية، المنتجات، السلة والدفع، طلباتي، التتبع، الصيانة الدورية والطارئة، أجهزتي، الدخول السريع والتسجيل |
| `prototype/staff-console.html` | لوحة موظف العمليات: المواعيد، الطلبات، أمر العمل وصفحة الفني، الدفع والعهد، المخزون، العملاء |
| `prototype/admin-console.html` | لوحة المدير: المستخدمون، الأدوار، الموافقات وقواعدها، الكتالوج، التقارير، الإعدادات، التكاملات، سجل التدقيق |
| `docs/gaps-report.md` | ثغرات ومشاكل وجدتها أثناء التصميم |
| `docs/test-and-roadmap.md` | نتائج الفحص الآلي وما هو للنسخة الأولى والثانية وما ينتظر الجهة |
| `docs/cost-and-tech-review.md` | مراجعة التكاليف والخطة التقنية (Supabase + React + Cloudflare) |

## التشغيل محلياً
كل ملف HTML مستقل. افتحه في المتصفح مباشرة بدون تثبيت. يحتاج اتصالاً بالإنترنت لتحميل الخط فقط.

## البنية المقترحة للنسخة الحقيقية
```
apps/store        متجر العميل (React مع عرض من الخادم أو توليد مسبق للـSEO)
apps/dashboard    لوحة الموظف والمدير (React، صلاحيات حسب الدور)
supabase/         الجداول، سياسات Row Level Security، ودوال Edge Functions
docs/             هذه الوثائق
```

## ملاحظات
- لا ترفع مفاتيح الخدمات (ميسر، سوبابيس service_role، الشحن) إلى GitHub. تُحفظ في متغيرات البيئة فقط.
- النماذج أُنشئت بالعربية واتجاه RTL، وتدعم الوضعين الفاتح والداكن.
